# zetto v0.2.0

Автор: Igor Kramar. 2026-10-30.

Ранний выпуск локальной базы связанных Markdown-заметок для Linux и macOS.
CLI и минимальный TUI поддерживают полный цикл: сохранить мысль в inbox,
отредактировать, связать и опубликовать.

В этой версии появились SQLite/FTS5, поиск текста и заголовков, просмотр
связей и локального графа, теги и вывод путей. Режимы stat/full/cached
явно показывают свежесть. Фоновый TUI замечает внешние изменения и допускает
CLI при открытом интерфейсе.

Markdown остаётся источником истины. Безопасная запись, рабочие копии
редактора и recovery не зависят от SQLite. Ошибка индекса после подтверждённой
записи возвращает saved:true и index_stale. Публикация требует связи на другую
опубликованную заметку; единственное root-исключение задано явно.

## Установка

Поставляется исходный архив `zetto-0.2.0-source.tar.gz` и `SHA256SUMS`.
Нужны Rust 1.89+ и C-компилятор для встроенной SQLite.

```sh
# Проверка SHA-256: Linux
sha256sum -c SHA256SUMS
# macOS: shasum -a 256 -c SHA256SUMS

tar -xzf zetto-0.2.0-source.tar.gz
cargo install --path ./zetto-0.2.0 --locked
zetto --version
```

Также можно установить непосредственно из тега:

```sh
cargo install --git https://github.com/IgorKramar/zetto.git --tag v0.2.0 --locked
```

Пакеты Linux/macOS с готовыми бинарниками и публикация в реестре Cargo
относятся к дальнейшей подготовке дистрибуции. Текущий пакет сохраняет
`publish = false`.

## Первый запуск

```sh
zetto --vault ./notes init
zetto --vault ./notes capture 'Мысль' --title 'Пример'
zetto --vault ./notes search 'Мысль'
zetto --vault ./notes tui
```

Для внешнего редактирования задайте EDITOR. Основные операции не требуют
rg, fzf, git или специальных шрифтов. В резервную копию включайте весь vault,
в том числе `.zettorc` и `.zetto/recovery`.

## Проверки и ограничения

79 Rust-тестов, fmt, clippy, YAML-корпус, реальный PTY, параллельные CLI,
занятая SQLite и смена git-веток. CI проверяет Linux на Rust 1.89/stable
и macOS stable. Найденные гонки сообщений TUI и ожиданий PTY исправлены
с проверками воспроизведения.

На дисковом синтетическом корпусе 5k заметок медианы: capture 16 мс,
cached FTS 36 мс, rebuild 1,67 с. Это наблюдения указанной тестовой среды,
а не гарантии задержки. На 50k stat превышает секунду, peak RSS TUI
около 500 MiB. Полные экраны Library/Focus/Inbox и палитра команд — следующие этапы.

Исходные серии измерений, непокрытые аварийные сценарии и платформенные границы:
[отчёт v0.2](https://github.com/IgorKramar/zetto/blob/v0.2.0/docs/architecture/reviews/2026-10-30-v0.2-verification.md).
Контракт хранения — format-v1. До 1.0 продолжается развитие интерфейса приложения;
этот выпуск не объявляет завершёнными beta/RC-проверки и ежедневную эксплуатацию.
