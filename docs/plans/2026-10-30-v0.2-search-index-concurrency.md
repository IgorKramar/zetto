## Результат и границы

Работающий CLI/TUI на тысячах заметок: производный SQLite/FTS5, поиск,
граф, внешние изменения и несколько процессов. Формат заметок, recovery
и правила публикации сохраняются. Нет демона, импортера, глобального
графа с симуляцией, полного Focus и палитры команд (это последующие версии).
Исходный полный обход остаётся независимым эталоном и резервным путём
проверок записи; обычные запросы используют индекс.

## Решения

SQLite хранится в XDG cache по SHA-256 канонического пути vault; каталоги
приватные. Внутренний ключ файла не равен ULID. Изменения files, links,
tags, aliases, diagnostics и FTS публикуются одной generation. Обход диска
выполняется вне write transaction; перед commit проверяется исходная
generation, при конкуренции сверка ограниченно повторяется. WAL и
ограниченный busy timeout координируют процессы без удаления занятой БД.

Stat-сверка проверяет наличие/размер/mtime; full перечитывает содержимое;
cached читает согласованный прежний snapshot без обхода. Сбой чтения
явен для конкретного пути. Проверка stat до/после чтения обнаруживает
нестабильный файл. Тела находятся в SQLite/файлах, в UI-каталоге только
метаданные; предпросмотр загружается отдельно. Запись Markdown не зависит
от индекса: после fsync ставится dirty marker; отказ — index_stale, saved:true.
До следующей сверки cached snapshot остаётся целиком прежним.

Resolver получает готовые карты ID/path/alias/stem, сохраняя порядок
format-v1 и неоднозначность. При изменении файлов повторно разрешаются
все ссылки; это линейный проход, пока измерения не требуют reverse dependency
оптимизации. FTS unicode61 с весом title; обычный запрос экранируется,
расширенный синтаксис только --fts. Literal/regex — отдельное ограниченное
потоковое чтение файлов. Fuzzy title/alias выполняется в worker через nucleo.

## Единицы реализации

1. **U1 — resolver и индекс.** `src/resolver.rs`, новый `src/index.rs`,
   общие helpers каталога в `src/app.rs`, зависимости/lockfile, `tests/index.rs`.
   Сначала проверить существующие resolver-примеры и добавить сценарий
   full/incremental, дубликатов и ошибок. Затем SQLite snapshot/сверка,
   schema/generation, FTS, отмена. Данные тела не копируются в UI snapshot.
2. **U2 — операции ядра.** `src/app.rs`, `src/error.rs`, `tests/app.rs`.
   Новый query API со свежестью; search/links/graph/tags/path/rebuild,
   отдельный preview и fuzzy. Capture не ждёт полного разбора графа.
   Записи и doctor работают при недоступном индексе; index_stale не превращает
   сохранённый файл в ошибку. Проверить реальными файлами и занятой БД.
3. **U3 — CLI и машинный контракт.** `src/cli.rs`, `tests/cli.rs`.
   Команды v0.2, full/stat/cached generation, пагинация и NUL-пути;
   usage для неверных regex/FTS, JSON/JSONL для всех новых команд.
4. **U4 — фоновые операции TUI.** `src/tui.rs`, новый worker/watch модуль,
   `tools/test_tui.py`. Ограниченные очереди, отмена superseded query,
   request IDs; async каталог/preview/поиск/сохранение, fuzzy picker.
   Notify — сигнал сверки; ошибка/переполнение запускают full,
   периодическая сверка страхует потерю событий. Ни callback, ни worker
   не меняют UI; старый ответ не заменяет новый. Сохранность форм v0.1
   и восстановление терминала обязательны.
5. **U5 — приёмка и документация.** Полный прогон владельцем ветки,
   ревью корректности/архитектуры, измерения 5k с отдельным обходом,
   smoke 50k, README/контракты/архитектура/отчёт, PR с зелёным CI.

Каждая следующая единица зависит от предыдущей. Исполнители работают
последовательно в одном checkout; коммиты и полный прогон принадлежат
владельцу ветки. Прогресс не записывается в тело плана.

## Проверки и завершение

- Full/incremental дают одинаковые пути, диагностики, разрешения и граф.
  Rename, удаление, смена title/alias, дубликаты, invalid YAML и смена
  git-ветки не оставляют старых рёбер. Full замечает same-size/same-mtime.
- Два CLI и TUI: нет перезаписи; dirty/cache generation согласованы;
  SQLITE_BUSY ограничен; rebuild не удаляет открытую БД.
- Ошибка индекса после сохранения: exit 0, saved:true, index_stale;
  doctor/raw и пользовательские данные доступны без SQLite.
- Поиск: Unicode, знаки FTS, literal/regex, пустая выдача, лимиты,
  отмена и пагинация; ID/path tie-break детерминирован.
- TUI: responsive navigation при фоновой работе; старый request ID
  игнорируется; ввод/resize/ошибка/сигнал сохраняют принятый текст;
  внешний редактор восстанавливает терминал и допускает CLI.
- cargo test, fmt, clippy, YAML-корпус и PTY проходят на MSRV/stable;
  CI Linux/macOS. Замеры 5k описывают среду, генератор, обход, поиск,
  capture, startup и память без подмены измерений обещаниями.

Слияние новой версии и публикация релиза — отдельные действия владельца.
