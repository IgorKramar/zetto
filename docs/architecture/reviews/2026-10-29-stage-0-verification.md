# Проверка пакета этапа 0

Автор: Igor Kramar. 2026-10-29.

Область: ADR-0005–0008 (на момент ревью Proposed, затем приняты владельцем), контракты, корпуса, проверочный
YAML-пакет и генератор. Приложение и v0.1–1.0 не считаются реализованными.
Исходное предложение/диаграмма владельца не изменялись.

## Ревью и исправления

Проверены корректность, тестовые ожидания, конвенции проекта и структура
изменений. Перед этим выполнена проверка повторного использования, качества
и эффективности; устранён лишний повторный parse одного emitted YAML.

1. **P1: потеря неизвестного YAML-значения.** `1` и `'1'` превращались в один
   String-ключ; parse→write сравнивал уже сокращённое дерево. Дефект
   независимо воспроизведён и подтверждён валидатором. Регрессионный тест
   сначала упал с `{"x-extra":{"1":"two"}}`; `no_schema: true` устранил
   coercion. Спецификация теперь требует кавычки для числовых ключей.
2. **Покрытие допустимых optional-списков.** Добавлены положительные tags/aliases
   и пустые списки с полным expected-деревом.
3. **Воспроизводимость корпуса.** Самопроверка сравнивает заново созданные
   small/invalid manifests и config с зафиксированными файлами; проверяет
   порчу файла, отказ перезаписи каталога и целостность Markdown byte ranges.

Применены все обнаруженные конкретные исправления. Незакрытых замечаний
к коду стенда по локальному ревью нет. Дополнительная adversarial-проверка
через другую модель была запущена, но не дала результата из-за ошибки
OAuth в её контексте выполнения; независимая модельная сверка не заявляется.
Исправление P1 проверено отдельным локальным валидатором и red/green тестом.

## Выполненные проверки

```sh
work-run -- cargo test --locked --manifest-path tools/format-probe/Cargo.toml
work-run -- cargo fmt --check --manifest-path tools/format-probe/Cargo.toml
work-run -- cargo clippy --locked --manifest-path tools/format-probe/Cargo.toml --all-targets -- -D warnings
work-run -- python3 tools/corpus.py --self-check
work-run -- python3 tools/corpus.py tests/corpus/small --check
work-run -- python3 tools/corpus.py tests/corpus/invalid --check
work-run -- python3 tools/corpus.py .generated/5000 --check
work-run -- python3 tools/corpus.py .generated/50000 --check
```

Результат: один параметризованный Rust-тест / 32 YAML-сценария проходит;
fmt/clippy без замечаний; самопроверка генератора и четыре manifest-проверки
проходят. В больших корпусах фактически 5 000 / 50 000 файлов, соответственно
4 999 / 49 999 рёбер. Все локальные ссылки в новых документах существуют,
диапазоны Markdown совпадают с исходными UTF-8 байтами.

`git diff --check` намеренно видит conflict markers в отрицательном примере
`tests/corpus/invalid/01ARYZ6S410000000000000008-zametka-8.md`. Это тестовый
ввод, не неразрешённый merge. Проверка остального diff с исключением ровно
этого файла проходит; маркеры не удалялись и проверка YAML не ослаблялась.
