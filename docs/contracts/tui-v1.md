# TUI: Library, Focus, Inbox

Автор: Igor Kramar. 2026-10-29. **Макеты приняты Igor Kramar**,
не снимки реализованного приложения. Основание: ADR-0007–0008.

## Library (120+ колонок)

```text
 zetto / Личное                                      / поиск  Ctrl-P команды
 ──────────────────────────────────────────────────────────────────────────
 КОЛЛЕКЦИИ        ЗАМЕТКИ                     Одна мысль — одна заметка
 Все       842    > Одна мысль — одна...       ────────────────────────────
 Inbox       7      Связи и контекст           Короткое утверждение своими
 Недавние           Как искать                словами и пример применения.
 Избранное          Стабильный ID
 Проверки    3                                -> Связи и контекст
                                              -> Стабильный ID
 ТЕГИ
 rust                                         ОБРАТНЫЕ ССЫЛКИ
 knowledge                                    От заметок к аргументам
 ──────────────────────────────────────────────────────────────────────────
 [СПИСОК] 842 опубликовано / 7 черновиков · сверено  n новая  c ввод  e править
```

`>` показывает выбор без цвета, `[СПИСОК]` — фокус. До 0.3 достаточно списка,
предпросмотра и действий 0.1; коллекции/обратные ссылки появляются с индексом.
Пустой vault после init показывает root и подсказку `c — записать мысль`.
Пустой поиск: `Нет совпадений`, запрос остаётся, Esc возвращает прошлую выдачу.
Идёт сверка: старые данные видны с текстом `Сверка…`; ошибка индекса:
`! Файлы сохранены, индекс устарел`, действие повторного обновления.

## Focus (одна заметка)

```text
 zetto / Чтение                           Alt-Left назад  Alt-Right вперёд
 ────────────────────────────────────────────────────────────────────────
 Одна мысль — одна заметка                           [опубликована]

 Короткое утверждение своими словами и пример применения.

 > [1] Связи и контекст
   [2] Стабильный ID
   [?] Отсутствующая цель — ссылка не найдена

 ОБРАТНЫЕ ССЫЛКИ
   От заметок к аргументам
 ────────────────────────────────────────────────────────────────────────
 [ТЕКСТ]  32%   Enter перейти  Tab ссылки  e править  g окружение  Esc назад
```

Стрелки/j/k прокручивают текст; в списке ссылок выбирают цель. Enter на broken
показывает причину, на ambiguous — кандидатов, без автоматического выбора.
Переход запоминает заметку/позицию; назад/вперёд восстанавливает их.
URL/asset открывается только явным действием из палитры, не от предпросмотра.
Экран ошибки не подменяет текст заметки пустым состоянием.

## Inbox (обработка)

```text
 zetto / Inbox                                         7 черновиков
 ────────────────────────────────────────────────────────────────────────
 ЧЕРНОВИКИ           ПРЕДПРОСМОТР                    СВЯЗЬ
 > Без заголовка     Мысль, которую нужно сохранить   Найти заметку: [     ]
   Будущая тема
   Пример            ! Нужен заголовок                > Связи и контекст
                     ! Нет связи на опубликованную     Стабильный ID

                     [e Редактировать]                [l Добавить связь]
                     [p Опубликовать: недоступно — 2 причины]
 ────────────────────────────────────────────────────────────────────────
 [ЧЕРНОВИКИ]  e редактор  l связь  p публикация  c ввод  Esc библиотека
```

Причины publish совпадают с CLI rule IDs. Нажатие `p` при запрете показывает
причины и сохраняет выбор/текст. После успеха — новая published заметка,
тот же ID, подтверждённый путь. Root имеет видимое `Исключение: корень`.
Ошибка редактора/конфликт показывает путь копии, оригинал не исчезает.
Ошибка индекса после сохранения даёт предупреждение, без повторного capture.

## Ввод и клавиатура

| Контекст | Клавиши и действие |
|---|---|
| Навигация | Стрелки/j/k выбор; Tab/Shift-Tab фокус панелей; Enter открыть; Esc закрыть верхний слой, затем вернуться |
| Library/Focus/Inbox | `/` поиск, Ctrl-P палитра, `?` справка, `n` new, `c` capture, `e` edit, `l` link, `g` локальный граф |
| Inbox | `p` publish с объяснением недоступности |
| История | Alt-Left/Alt-Right назад/вперёд |
| Палитра | Ввод фильтрует Action; Enter вызывает, Esc закрывает; показывает доступность и текущую клавишу каждого действия |
| Текстовый ввод | Все печатные символы, включая j/k/n/p/? — текст; Enter новая строка в capture, Ctrl-Enter сохранить; в поиске Enter принять выбор |
| Завершение | `q` вне ввода — выход; Ctrl-C — управляемое прерывание с сохранением принятого ввода; отмена несохранённого поля требует явного discard/save |

Capture — многострочное поле; bracketed paste вставляется как текст.
Esc с непустым вводом открывает выбор «Сохранить в inbox / Продолжить ввод /
Отбросить», default «Продолжить». Во время Ctrl-C текст поля сохраняется
как draft до выхода; если I/O не позволяет, ошибка показывает recovery либо
сообщает, что текст не подтверждён, вместо ложного «сохранено».
Resize не сбрасывает ввод/выбор. Состояния input/modal не пропускают символы
в навигацию. Несохранённый ввод не обещается пережить SIGKILL/потерю питания;
после подтверждённого capture работает протокол долговечной записи.

## Размеры, тема, жизненный цикл

120+ колонок — три области; 80–119 — список+текст, коллекции через палитру;
60–79 — один экран со сменой списка/текста по Tab; меньше 60 колонок либо
12 строк — компактное сообщение с выходом, состояние ввода сохраняется.
Длинный title обрезается по ширине терминальных ячеек; полное значение
доступно в Focus. Combining marks/CJK/emoji не режутся по байтам.

| Токен Gruvbox | Цвет | Дополнительный признак |
|---|---|---|
| background | `#282828` | Фон |
| surface | `#32302f` | Подложка активной области |
| text | `#ebdbb2` | Основной текст |
| muted | `#a89984` | Подписи |
| accent/focus | `#d8a657` | `>` и имя фокуса |
| link | `#89b482` | `->`, `[номер]` |
| error | `#ea6962` | `!` и текст причины |

Нет требования Nerd Font. Светлая/монохромная тема и настройки — beta.
Цвет не является единственным носителем информации. Перерисовка по событию,
таймер только при меняющемся состоянии. Вызов редактора сначала возвращает
терминал в обычный режим, затем возобновляет TUI. Выход/ошибка/panic/Ctrl-C
восстанавливают raw mode, alternate screen, cursor и paste. Suspend/resume
проверяются через PTY до beta; статический макет это не подтверждает.
